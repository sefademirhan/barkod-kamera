# Barkod Kamera

Mobil uyumlu, fotoğraftan barkod algılama ve CODE128/EAN13/CODE39 barkod üretme sitesi.

## Özellikler
- Telefon kamerasıyla fotoğraf çekme veya galeriden görsel seçme
- Tarayıcı destekliyorsa fotoğraftaki barkodu algılama
- OCR ile ürün/SKU numarası bulmaya çalışma
- CODE 128, EAN-13 ve CODE 39 barkod üretimi
- Barkodu PNG olarak indirme

## GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
